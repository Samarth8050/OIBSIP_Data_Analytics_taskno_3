# 📱 Google Play Store Analytics Dashboard

## 🚀 Project Overview
This project focuses on analyzing the **Google Play Store dataset** to uncover valuable insights about app categories, ratings, installs, reviews, pricing, and user sentiments.  

Using **Power BI**, **Python**, and data visualization techniques, the dashboard provides an interactive overview of Android app market trends and user behavior.

---

# 🎯 Objectives

✅ Analyze Google Play Store app market trends  
✅ Explore app categories and popularity  
✅ Compare Free vs Paid applications  
✅ Study relationships between ratings, installs, and reviews  
✅ Perform sentiment analysis on user reviews  
✅ Build an interactive Power BI dashboard for insights

# ⚙️ Steps Performed

- Removed duplicate records
- Handled missing values
- Converted installs and price into numeric format
- Removed symbols like `+`, `,`, `$`
- Cleaned and standardized categories
- Processed sentiment review data

# 🔍 Key Insights

✅ Free apps dominate the Play Store market  
✅ Family & Game categories have the highest number of apps  
✅ Apps with higher ratings generally achieve more installs  
✅ Positive sentiments dominate user reviews  
✅ Most apps maintain ratings between 4.0 and 4.5 ⭐
